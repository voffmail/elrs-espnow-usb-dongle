ELRS ESP-NOW USB Dongle

Прошивка esp32-c3-usb — только для ESP32-C3 с native USB. Не для DevKitM-1/CP2102N (esp32-c3).

Версия: загрузка…
Нужен Chrome или Edge на компьютере с поддержкой Web Serial. Открой страницу по HTTPS (GitHub Pages) или на localhost.

Прошивка стирает NVS: phrase/UID/канал нужно будет задать заново. Скачать образ вручную: firmware-merged.bin.

Перед прошивкой закрой ELRS Dongle Stub, монитор порта, PlatformIO и serial_bridge.py — они могут держать порт.

Как прошить

  1. Подключи донгл к компьютеру по USB.
  2. Открой эту страницу в Chrome или Edge на компьютере.
  3. Нажми «Прошить донгл» и выбери последовательный порт.
  4. Подтверди стирание и дождись завершения. Донгл перезагрузится.
  5. Настрой phrase/UID и target в Android-приложении или через tools/dongle_config.py.

Web Serial не работает в мобильных браузерах. Если прошивка не запускается, используй PlatformIO/esptool.
